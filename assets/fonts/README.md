Lettering fonts for speech bubbles, from the Google Fonts repository
(github.com/google/fonts, `ofl/`), each under the SIL Open Font License 1.1
(`OFL-*.txt`, which allows bundling and redistribution):

- `ComicNeue-Bold.ttf` — Comic Neue Bold (dialogue)
- `Bangers-Regular.ttf` — Bangers (shouts and sound effects)

`scripts/gimp-dev.sh` links them into the GIMP profile's `fonts/` folder.
